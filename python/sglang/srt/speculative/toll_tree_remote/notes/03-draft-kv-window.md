# Draft KV 窗口

这份报告记录影子行和截断窗口。E1′ 的判定留在 `raw/gate-window/DECISION.md` 前半。E2 以后的格子在同一目录：`e2-verdict.json`、`step0-verdict.json`、`step0b-verdict.json`、`opt-ab-verdict.json`、`e4e5-verdict.json`。输出分叉在 `raw/gate-window/fork/`：`d1-verdict.json`、`d23-verdict.json`、`d4-verdict.json`、`s-verdict.json`、`forkcheck.log`、`k.log`、`deep-v.log`、`logit.log`、`resid.log`、`tree.log`、`sub.log`。逐格 json 和 `raw/ext-e2.csv` 也在 `raw/` 下。

E1′ 的 host +3% 不通过记录保留，没有再改刷新。之后按绝对预算跑了 E2。过线后收了每层准备，再跑 E4 和 E5。窗口默认仍是关闭，设置 `SGLANG_OPT_DRAFT_KV_WINDOW` 才打开。

## 修订后的 E1′ 判据

正确性沿用 E1b，已经通过：\|Δlogit\| ≤ 1e-2，top-N 一致率 ≥ 99.9%。E1′ 把核对关掉。

成本是主判据，B 相对 A：

- 每层 GPU ≤ +3%
- 每层 host ≤ +3%
- D_crit / 每轮层数 ≤ +3%

吞吐是次判据：\|mean(B) − mean(A)\| / mean(A) 不超过 A 组各次最大相对差，也不超过 1% 里更大的那个。

作废只看 Target：某一次的验证前向窗口中位数，偏离该组各次中位数的中位数超过 10%，这一次作废。不看 Draft，避免按结果挑格子。

同一条 prompt（长度加前 8 个 token）在 A、B 之间的接受长度差，不超过 A 组内部同样配对的最大差。

顺序是 A B A B A B。只重启 Draft，Target 不重启。每次用同一组请求预热。host 超过 +3% 时不进入 E2，先改成只追加新的树列，再重跑 E1′。

## 待办：空闲内存的选路

compact FIA 是否启用由每个 rank 自己的 `torch.npu.mem_get_info()` 决定。S1 在 `--mem-fraction-static 0.78` 下，rank 0 空闲 199.96 MiB 时跳过，rank 1 空闲 154.55 MiB 时仍去分配 252 MiB 并退出。空闲内存的选路应对所有 TP rank 取最小值。`tree_paged_fia` 不读这块空闲内存。KV 预算用的是本 rank 的 `available_size()`，图捕获失败也不看空闲内存。这次不改代码。
