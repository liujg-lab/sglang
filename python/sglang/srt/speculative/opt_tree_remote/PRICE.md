# 全局价格的树控制

**状态：** 设计阶段，没有实现，也没有实测。计划作为默认关闭的开关写在 `opt_tree_remote/`，不放进已停止的 `toll_tree_remote/`。本文是 2026-11-09 版，取代 11-07 版的“批共享价格规则”。当前 `OPT_TREE_REMOTE` 仍是固定的 N 和 τ。

实验步骤不写在这里。窗口和 4096 分叉的结论在 [../toll_tree_remote/notes/gate-window/DECISION.md](../toll_tree_remote/notes/gate-window/DECISION.md)，V0–V6 的结论在 [../toll_tree_remote/notes/validate/DECISION.md](../toll_tree_remote/notes/validate/DECISION.md)。

### 一句话

> 把时间按实测吞吐 Θ 换算成 token，深度、验证数、宽度、Draft KV 窗口和投机开关都用这同一个价格结算。深度逐层决定；验证数在树长完后按已捕获的档位选；宽度和窗口按上下文在少数档位之间选；投机开关看相对 Target-only 的加速比。

### 和 11-07 版的差别

| 项 | 11-07 版 | 现在 | 依据 |
|---|---|---|---|
| 调哪些量 | 只调深度 | 深度、验证数 K、宽度 W、窗口 w、模式 | 只调 τ 最多 0.36%；N=16 在 b=1、4096 上比 N=8 高 12.9%，在 b=8 上慢 14%；短前缀 b≥7、4096 b≥3 时 Target-only 最好 |
| 深度的收益 | 每个请求的 ρ·ĝ | J 的增量，含 K 的选择和换档成本 | 有的层只有在 K 换到更大档位时才值得长 |
| 成本 | 参数拟合 c0、c_r、κ | 在线分层查表，参数模型作先验 | 短前缀拟合的模型用到 4096 时误差 25–55%；b=2、4096 的预测偏差 30% |
| 接受率 | ρ_i | 按深度校准，加差距加权的标签，再乘 ρ_i | 合成前缀和自然提示的接受长度差 2 倍；平局附近的标签受数值噪声影响 |
| 网络 | 通过 Θ 间接起作用 | 不变；等待期间不继续长树（σ=0） | 实验显示继续长树命中率低 |

| 深度规则的形式 | — | 全局 Θ，不用 AdaCost-Tree 的单轮比值 ΔW/ΔC > W/C | 单轮比值优化的是每轮自己的效率，不是长期吞吐（定理 2） |

### 决策变量

| 时间尺度 | 变量 | 取值 |
|---|---|---|
| 慢环（秒级，按上下文） | 模式（投机 / Target-only）、宽度档位 W、Draft KV 窗口 w | W ∈ {4, 8, 16}，w ∈ {256, full} |
| 每轮结束时 | 验证数 K，整批共用 | 已捕获的档位，例如 {5, 9, 17} |
| 快环（每层） | 每个请求是否继续长；整批是否再开一层 | 到 max_depth 为止 |

上下文 `x = (b 档, 前缀长度档, RTT 档)`，由负载和网络决定，不由算法选择。

### 模型

**1. 目标：全局价格（Dinkelbach）**

```text
Θ* = max E[A] / E[T]   ⇔   每轮最大化  A − Θ·T，Θ 取实测吞吐，迭代到 Θ*
```

Θ 是 1 ms 值多少个 token。所有决策都用它比较"多得多少 token"和"多花多少时间"。

**2. 收益：校准后的接受概率**

```text
A = Σ_i [ 1 + Σ_{v∈S_i} π̂_v ]

π̂_v = h_{d(v)}(w_v) · ρ_i
  w_v ：Draft 路径概率，即沿路概率的乘积
  h_d ：按深度分桶的保序回归，在线拟合
        • 删失：只有被接受节点的孩子才有标签
        • 标签权重 = min(1, Target 在该位置的 top-1/top-2 差距 / 1 nat)
  ρ_i ：每个请求的 Beta 收缩系数

下一层的预测收益：ĝ_i(d+1) = r̂_i · Δ_i(d)
  直接用本层的 Δ 当作下一层的收益会多长一层
```

**3. 时间：关键路径**

```text
T   = R + V_K(b, Σℓ) + Σ_每层 L_m
L_m = c0(b) + Σ_{i∈A_m} c_i(W, ℓ_i, w)    每层固定开销（整批分摊）+ 每个请求的行开销
R   ：网络往返，实测为 t_wait − t_target
```

- 等待 Target 验证和网络回程时，Draft 不继续长树，所以 Draft 的每一层都按全价 Θ 计算。
- 网络只通过 R 起作用：R 变大，每轮变慢，Θ 下降，所有门槛一起降低。

**4. 成本：在线分层查表**

```text
表格键：(执行路径 图/eager, b 档, W 或 K 档, Σℓ_eff 档, w)，每格记 EMA 均值和方差
先验（AdaCost-Tree 的函数形式加上 b 项，做 NNLS）：
  c_layer = α + β_b·b + β_bW·b·W + β_WL·W·Σℓ_eff        ℓ_eff = min(ℓ, s + w)
  V_K     = α_v + β_K·b·K + β_KL·K·Σℓ + β_K²·(bK)²
估计值 = n/(n+n0)·表格值 + n0/(n+n0)·先验
```

访问过的格子直接用实测值，没访问过的格子用先验，并带上不确定度。

**5. 深度和验证数的耦合：价值函数 J**

```text
J(d) = max_{K∈档位} [ Σ_i Σ_{r≤K} π̂_i(r) − Θ·V_K(b, Σℓ) ]
```

- 选 K 不花 Draft 时间，可以推迟到树长完再选。
- 同样的 K，取校准分数最高的前 K 个一定最优。路径分数沿边只减不增，所以前 K 个自动构成连通的树。
- 深度决策用 J 的增量：新节点只有能进入最优的前 K 个才算数，K 换档的成本也已经扣掉。

例子：K 只能取 4 或 8 个草稿节点，Θ·V 分别是 5.0 和 5.6 个 token，每层成本 0.3 个 token。第 3 层在 K 固定为 4 时只多 0.15，不值得长；允许 K 换到 8 后，J 增加 0.4，值得长，最后选 K=8。

### 求解

**快环（每层）：**

```text
请求 i 继续：   E[J 中 i 的增量]   >  Θ · c_i
整批再开一层：  E[J(d+1)] − J(d)   >  Θ · L_{d+1}

K 档位固定时，退化为：
  ρ·ĝ_i > Θ·c_i      和      Σ_{i∈A} (ρĝ − Θ·c_i)⁺ > Θ·c0
```

**每轮结束（验证数）：**

```text
K* = argmax_K J(D)；验证集取校准分数最高的前 K* 个
```

- 冷启动、还没有 Target 验证成本表时，用 AdaCost-Tree 的 `K = max(N, κ)` 作为退路。
- 以约 5% 的比例强制保留最新一层，专门收集深层节点的校准标签。不做"K 不变、替换叶子"的定长 frontier 保护：同样的 K 下，它的总分一定不高于前 K 个。

**慢环（每个上下文选一个臂）：**

```text
臂 a = (W, w, 模式)
对每个臂：用模型预测 Θ(x, a) 和置信区间
          （成本表 + 校准接受量 + 反事实估计：用宽树估计更窄档位的接受量）
只探测"模型上界 > 当前臂实测下界"的臂
探测：基线和探测交替排进同一个周期，抵消负载漂移
奖励：墙钟时间实测的 S_b，只用整体量（token/时间），每个窗口至少累积一定 token 数
      不按请求对比输出：换臂以后文本会在不同位置走岔
护栏：每个臂按差距分档统计翻转率（见"无损判据"）
切换：下界差距 > 切换成本（图已捕获时约为 0），并有滞回
不同上下文之间通过参数先验共享统计量
```

**投机开关：**

```text
S_b = Θ_投机 / Θ_AR(b, Σℓ)        Θ_AR 用 Target-only 走图时实测的步时表
S_b 的上界 < 1 − 余量，并持续 k 个窗口  →  切到 Target-only（必须走图路径）
```

这是 AdaCost-Tree 式 5（等效 Target 加速比）的 batch 版。

### 无损判据

在 bf16 下，只要验证的计算形状变了（行数、图还是 eager、batch 组成），Target-only 自己也做不到逐 token 一致。4096 t=72 的分叉已逐层确认是数值放大，记录在 [../toll_tree_remote/notes/gate-window/DECISION.md](../toll_tree_remote/notes/gate-window/DECISION.md)。

| 项 | 定义 |
|---|---|
| 噪声基线 | Target-only 跨形状（b=1、4、8，以及预填充打分）之间的分叉 |
| 指标 | 按差距分档的翻转率：P(翻转 \| Target top-1/top-2 差距 ∈ {<0.5, 0.5–1, 1–3, >3 nat}) |
| 判据 | 每一档里，投机的翻转率不显著高于噪声基线，例如 95% 置信上界 ≤ 基线的 2 倍 |
| 一票否决 | 差距 > 3 nat 的档位显著偏高时，当作疑似 bug，回到逐层排查 |

阈值是建议值，按论文口径再定。逐 token 一致仍作为记录项保留。

### 理论结果（证明思路阶段）

| 编号 | 结论 | 前提 |
|---|---|---|
| 定理 1 | 档位固定时，"请求退出 + 整批停止"两条阈值规则恰好最大化 `A − Θ·T`。证明：给定最大层数 M，每个请求取 d_i = min(M, d_i*)；把 M 加 1 的边际收益随 M 单调不增，第一次 ≤ 0 处即最优。档位可变时，在各档位上分别求解再取最大，仍然精确 | (A1) 逐层收益递减；(A2) 成本可加 |
| 定理 2 | 全局 Θ* 最大化长期吞吐 E[A]/E[T]；单轮比值规则只有在每轮完全相同时才最优，否则好猜的轮长得太浅、难猜的轮长得太深。例子：两类轮各一半，单轮比值得 0.423，全局 Θ 得 0.4286 | 各轮独立同分布（更新回报定理加 Dinkelbach） |
| 推论 | 树深和验证数随 RTT 不减 | 把 Delay-Adaptive 的链式结论推广到树和 batch |

(A1) 有数据支持：接受深度近似几何分布，r 在 0.71–0.77 之间。11-07 版设想过的"空闲时间单调性"已随预起草一起删除。

### 论文里的取舍

| 内容 | 处理 |
|---|---|
| 全局价格和定理 1、2（含相对单轮比值的最优性） | 核心贡献 1 |
| batch 共享的 J 和按档位选 K | 核心贡献 2 |
| 在线成本表加模型引导的选臂（离散图档位、图和 eager 两条路径、NPU 和 CUDA） | 核心贡献 3 |
| 校准、S_b 开关、统计无损判据 | 方法里各写一段 |
| Draft KV 窗口、跳过路径走图 | 写进实现一节；窗口作为 κ·ℓ 项的干预验证 |
| 等待期间预起草、定长 frontier 替换、连续宽度爬山 | 删掉 |

**已知风险：**
- 在 3–5 ms 的 RTT 下，调好的静态规则离最优只差 0–13%（只有 b=1、4096 那一格是 12.9%）。收益必须在网络变化和混合负载下证明。
- 删掉预起草以后，网络这一维的增量只剩"把延迟单调的结论推广到树和 batch"，比 Delay-Adaptive 多出的部分有限。
- 如果混合负载加 RTT 时间表下，相对最好的静态规则收益 < 5%，论文主线改为系统实现、Draft KV 窗口和成本模型。
- 发表还需要第二组模型和标准数据集。
