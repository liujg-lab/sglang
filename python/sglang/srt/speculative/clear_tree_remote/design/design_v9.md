## 定位

ClearTree 回答跨机投机解码里的三个问题：

| 问题 | 内容 | 对应贡献 |
|---|---|---|
| 概率 | 只有路径接受反馈、请求之间又共享难度效应时，怎样估计树上节点的联合路径接受概率 | 核心贡献 1：两段式 GLMM、请求随机效应、按路径联合积分 |
| 优化 | 在全局 top-W、同步嵌套和矩形验证的约束下，怎样权衡收益、计算成本和以后继续扩展的价值 | 核心贡献 2：best-first、嵌套子集 DP、验证时重选 K |
| 控制 | 怎样用可测量的全局吞吐价格，把预测和在线资源约束纳入滚动决策 | 系统贡献 3：全局价格、滚动规划、在线成本学习、自适应投机开关 |

只声称两件事：给定预测模型时规划是最优的；相对真实两阶段问题的近似误差可以测量。理论最优、模型内最优、系统实测三种"最优"分开说明（第二节）。

## 一、约束、适用范围和符号

**执行约束：**

| 约束 | 来源 |
|---|---|
| 每个请求每层从上一层所有节点的孩子里，先排除终止候选，再按 Draft 原始路径分数取全局前 W 个 | OPT 的 `expand_from_topk`（`parent_cols = top_index // n`） |
| 同步嵌套：同一次层前向里所有请求深度相同，所以 𝒜_{m+1} ⊆ 𝒜_m | `_shared_depth` 在深度不同时报错 |
| 矩形验证：整批共用 K，每个请求送 K 个节点，Target 一次处理 K+1 个 token | Target 的树验证图 |
| b ≤ 8 | Draft 的图档位 |
| 树的 KV 每轮开始时按需求记账预留，物理槽位逐层分配。本轮结束只释放未被接受的分支；被接受路径的槽位按 OPT 的 KV 复用（tree lease）转给请求，不再计入树预算。page=128 不发布 lease，被接受路径在下一轮 ingest 时重算 | Draft 的 KV 池是全局共享的；`opt_tree_lease.py` |
| 等待 Target 期间不继续长树，只补算最后一层 | 实验显示命中率低（D9） |

**适用范围：**
- 只支持 greedy 验证；开了 RPD 时不启用。batch 里有非 greedy 或受约束解码的请求时，这一批走 OPT 规则。
- Draft 拿不到 stop id 时，只有部署时显式声明"请求不带自定义 stop token id"才启用；EOS 集合从模型配置读取。
- Draft 拿不到剩余预算 r_i 时，短输出的负载会损失 2–4%（第十节），先做压力测试再决定是否启用。
- SR 的 PREFILL 带 `max_new_tokens` 和 stop token id（`sr_protocol.py` 的 `_sampling_params_to_dict`），但 Draft 会为窗口预算就地调高 `max_new_tokens`（`sr_draft_scheduler_mixin.py`），所以 r_i 要用调高之前存下的原值。
- 多 token 的 stop 字符串不在模型范围内。

**符号：**

| 符号 | 含义 |
|---|---|
| x | 上下文 = (b 档, Σℓ 档, RTT 档, 带宽档, 执行路径)，由外部决定 |
| 𝒦、W、w | 验证档位（例如 K+1 ∈ {5, 9, 17}）；Draft 每层宽度；Draft KV 窗口 |
| 𝒜_m、𝒜′、ℰ_m | 第 m 层的活跃请求集合；候选子集；还能有收益地建第 m 层的请求 { i : D_i^reward ≥ m } |
| T_m、H_m | 已建好的树；截至第 m 层的观测历史 |
| K_g、K_v | 建树规划用的 K；验证用的 K |
| 𝒱_i^K | 请求 i 在 K 下的验证集合（best-first 选出的 K 个节点） |
| C_v、q_u、q1_v、Q_v | v 处排除终止 token 后的 top-C 候选；孩子 u 的概率；C_v 里的最大概率；C_v 的概率和。q 一律是全词表 softmax 的原始概率：排除终止 token 只改变候选资格，不重新归一化 |
| y*_v、H_v、o_v | Target 在前缀 v 之后的 argmax；命中 H_v = 1[y*_v ∈ C_v]；v 是否未被接受 |
| π̄_v | 节点 v 被接受的概率（对参数联合积分后） |
| r_i、D_i^build、D_i^reward | 剩余 token 预算；能建多深；还有正收益的最深一层 |
| N_snap、N_param | 快照抽样次数；参数抽样次数 |
| Θ* | 全局时间价格（忙时吞吐，token/ms） |

## 二、统一的决策模型

```text
状态：s_m = (m, 𝒜_m, T_m, H_m)
动作：生长 𝒜′ ⊆ 𝒜_m ∩ ℰ_m（非空），或者停止
终止：树建完后选 K_v 和验证集合；收益 R^K(T) = Σ_i Â_i^K(T) − Θ*·ΔT_K

V*(s_m) = max{ 停止：max_K R^K(T_m)，
               生长：max_{𝒜′} −Θ*·[c_Draft(𝒜′) + C_plan,m+1(𝒜′)] + E[V*(s_{m+1}) | H_m, 𝒜′] }
```

ClearTree 对这个问题做了以下近似：

| 编号 | 近似 | 组件 |
|---|---|---|
| ① | 未来各层的随机结果换成期望增量 μ̂（确定性等价） | GLMM、联合积分、快照库、μ̂ |
| ② | 终止价值 max_K R^K 换成 R^{K_g}，K_g 在第 1 层选定 | 选 K_g；这样各层增量可加，可以用子集 DP |
| ③ | 每层重新规划，吸收新观测 | 滚动规划 |
| ④ | 树建完后按 max_K R^K(T) 选 K_v | 验证时重选 K（命题 3） |
| ⑤ | 跨轮问题用全局价格 Θ* 处理，Θ* 是滚动优化的影子价格 | 定理 2 |
| ⑥ | 探索（强制 K 探测）放在每轮问题之外，作为记录了概率的随机化，净成本单独记账 | 强制 K 探测 |

| "最优"的三种含义 | 内容 | 依据 |
|---|---|---|
| 理论最优 | 静态确定性规划模型：未来各层的增量和成本在第 1 层已知且不变 | 定理 1、命题 1 |
| 模型内最优 | 预测模型下的随机两阶段问题 | 合成实验：离精确最优不到 0.1% |
| 系统实测 | 真实闭环吞吐 | 阶段 5 |

## 三、模型

### 1. 目标和收益

```text
优化目标：Θ*_busy = EMA(A^real) / EMA(T^real)，只算有请求在跑的轮次
  一轮（Draft 端）：从收到 STEP 到收到下一条 STEP 或 FINISH；中间夹了空闲或 PREFILL 时，这一轮的时间用预测值代替并计数
  请求在本轮结束时：FINISH 带这一轮提交的 token（D51，SR 新增可选字段，方案见 progress/plan.md 3.1），提交数 = 尾部长度；
           没带尾部时（旧 Target 或隔了不止一轮），用 base_committed_len 减去 Target 坐标的 prompt 长度和已确认长度
  A^real = Target 上 completion_tokens 的增量
           （包含 EOS/stop token 本身，截掉其后的 token，封顶 max_new_tokens；不能用接受长度）
另外报告：Θ_wall、P50 和 P99 延迟；Θ_正常、Θ_探索（强制 K 轮）、Θ_生产（包括全部实际开销）

收益（引理 0）：
  一般式：Â_i^K = Σ_{v∈𝒱_i^K} π̄_v + 1 − Σ_{v∈𝒱_i^K ∩ Term_i} π̄_v
  适用范围内树里没有终止节点：Â_i^K = Σ_{v∈𝒱_i^K} π̄_v + 1
  终止节点在本轮的边际价值为 0

时间：T̂ = T_公共 + C_Draft + C_plan + ΔT_K
  T_公共：比较方案时消掉，计算 Θ* 时计入
  ΔT_K：K 固定、验证形状为 b×(K+1) 时对所有子集相同，不参与子集比较，但进入选 K 和吞吐记账
```

### 2. 接受率校准（两段式 GLMM）

```text
估计对象：â_u = P(H_v = 1, y*_v = u | x_v, δ_i, v 被接受)
  π_u = 路径上 â 的乘积；v 没被接受时它的孩子贡献为 0，所以只需要"父节点被接受"条件下的量

第一段（命中）：logit P(H_v = 1 | x_v, δ_i) = a_{d,W,w} + γ1·x1 + γ2·x2 + δ_i(t)
  x1 = logit(clip(q1_v))，x2 = logit(clip(Q_v − q1_v))，clip 到 [1e-4, 1−1e-4]，都在 C_v 上计算
  γ ≥ 0，加岭惩罚；b、K、Σℓ 档等上下文变量只在残差检验显著时加入截距
  δ_i(t)：请求随机效应，随位置缓慢变化。按已提交位置衰减加权：ω_v = λ^(p_now − p_v)，λ = 0.9
          （M1 下每个已提交 token 恰好对应一个标签，所以也等于每个标签衰减一次；有效记忆约 10 个 token）；
          先验 N(0, σ_δ²)；拟合用拉普拉斯近似或数值积分，不用 PQL。
          这是跟踪非平稳的工程近似（加权惩罚似然），不是某个动态模型的似然，后验方差也只是近似；
          命题 4 只覆盖静态 δ_i
第二段（兄弟分配）：P(y*_v = u | H_v = 1) ∝ q_u^β，只在 C_v 内归一化；β 在线学习（一维牛顿法）；按深度的 β_d 由 E2 决定
边界情况：候选数为 0 时 P(命中) = 0；候选数为 1 时第二段概率为 1
版本：θ、β、δ 和成本表在一轮之内冻结，后台拟合的结果只在下一轮的 ① 换入。引理 3 和 DP 比较的都是同一版本下的节点权重
```

**样本：**
- 第一段用方案规定的父节点；第二段只用其中 H = 1 的，类别是 y*_v 在 C_v 里的位置。
- 不需要"尾部"类别，C_v 之外的 token 永远不会成为树节点。
- 默认方案 M1 只用被接受的父节点。用不用未接受父节点（M2–M4），由 E2 的等价性检验决定（第七节）。

**M1 的似然（命题 4）：** 哪些父节点会被观测到，只取决于同一请求里已经观测到的结果、树里有没有这个孩子、按已观测数据做的策略决定。所以选择机制可以从似然里约掉，GLMM 的边际似然就是正确的似然；容易的请求贡献更多样本，也不会带来偏差。成立的前提：
- 每个被接受父节点的标签都要记录，包括每轮链条末端没命中的那一个；
- 不能有按结果丢标签的路径（例如请求结束时跳过补算前向）。

**标签来源：**
- y*_v 是下一个已提交的 token（包括 bonus）。
- C_v 的概率来自 Draft 每层的前向；最深一层来自回包后的补算前向，在 `_append_layer_bonus_ids` 附近同时存下。补算要覆盖每个请求自己的最后一层，包括提前退出的请求（`forward_deferred_final_layers` 已经按深度分组）。page=128 没有补算，单独建校准模型。
- 请求在本轮结束时，FINISH 带上这一轮提交的 token（D51，方案见 [progress/plan.md](progress/plan.md) 3.1），标签和普通轮一样打。
  - 截断只丢后面的 token，所以尾部覆盖到的每个位置都是 Target 的 greedy 结果，可以照常打标签。
  - 尾部停在被接受路径内部时（在某个被接受节点上命中 stop 或 max_new_tokens），这个节点的孩子没有 y*，记为删失，不算拒绝。这是按位置删失，不看结果，不违反命题 4 的前提。
  - 仍会缺失的情况按原因计数：旧 Target 不带尾部、两次确认之间隔了不止一轮、最后一轮没有验证这棵树。E2 报告缺失比例，离线用 Target 的 `t_round` 补齐。
- 特征缺失时，要假设"给定 x_v、深度、是否最后一层，缺失和是否命中无关"，并用随机抽取的审计轮（额外前向）检验。没有补算前向的配置单独建校准模型。

### 3. 终止语义、建树和 KV

```text
Draft 选候选的顺序（规划器的模拟完全照此执行）：
  每个父节点取 top-(C + |终止集合|) 个孩子 → 排除终止 token（EOS 和 stop token id），保留前 C 个 → 全局 top-W
  → 下一层从保留的节点继续展开。路径分数、x1、x2、Q_v 都用原始 q，只有第二段在 C_v 内归一化

每轮开始时：
  D_i^需要   = min(D_max, max(0, r_i − 1))
  KV 按需求注水：取最大的 L，使 Σ_i W·min(D_i^需要, L) ≤ 可用 KV；D_i^KV = min(D_i^需要, L)
             按分配器的单位算（CUDA 按 token，NPU 按 128 的页）；只记账，本轮结束释放未被接受的分支（被接受路径见第一节）
  D_i^build  = min(D_max, D_i^KV)
  D_i^reward = min(D_i^build, max(0, r_i − 1))       深度 ≥ r_i 的节点边际价值为 0，不建
验证集：best-first，终止节点价值记为 0，排在最后，只在补齐时用
```

| 回退情形 | 处理 | 误差 |
|---|---|---|
| 拿不到 stop id | 默认不启用；有部署声明才启用 | 如果 stop 节点留在树里：每个请求只终止一次，累计期望高估 ≤ D^build 个 token；stop 子树每轮最多占 K 个验证名额 |
| 拿不到 r_i | D_i^reward = D_i^build | 只在 r_i ≤ D^build 的轮次高估（最多 D^build 轮），每个请求累计多算 ≤ D^build 个 token；合成模拟：输出 24–48 个 token 时吞吐低 1.7–4% |

排除终止候选只改变草稿，验证仍是 greedy，输出不变。

### 4. 联合积分

| 变量 | 抽样方式 | 在什么范围内共用 |
|---|---|---|
| (θ, β, δ_活跃请求) | 联合拉普拉斯近似 N(ẑ, H⁻¹)；新请求的 δ 从先验抽 | θ 共用于所有节点；β 共用；δ_i 共用于同一请求的所有深度 |
| 快照 | 每个外层场景、每个请求、每层抽一次 | 同一请求这一层的所有父节点 |

```text
π_root^(r) = 1；π_v^(r) = π_parent^(r) · â_v^(r)          沿路径一直连乘到底
π̄_v = (1/N_param) · Σ_r π_v^(r)                           最后才取平均，中间层不能先平均再连乘
```

### 5. 下一层预测（快照库）

```text
快照：Draft 实际算出的孩子分布（已排除终止 token、补足到 C 个的原始概率）、终止 token 的概率和 p_term，
      以及当时的层级特征 φ（父节点的 q1、路径分数、这个请求最近的命中率）
快照库：按 (d, W, w) 分层的环形缓冲，只保留当前策略下的数据；
        检索用这个请求最近的快照，不够时按 φ 取 kNN，再不够退回粗一级分层
μ̂_i^K(m)，只算 m ≤ D_i^reward：
  外层，共 N_snap 次（第一版取 4）：抽快照 → 为当前每个父节点生成孩子（快照里已排除终止候选，不再过滤）→ 全局 top-W
  内层：孩子的 π̄ 按第 4 节积分（N_param 组，共同随机数）
  插进各 K 档的前 K 个（终止节点价值为 0），得到 ΔG_s^K（各 K 档共用样本）；对 N_snap 次取平均
前两层：链式的整层模拟
更远的层：μ̂(m+k) = min( μ̂(m+k−1) · r̄_{m+k−1}, U(m+1) )，U = Σ_{p∈L_m∩𝒱_m}(p − m_m) 是结构上界（引理 3）
```

快照库对"本来会停止"的状态是否有选择偏差，以及要不要做随机扩展探测，推迟到第二步（第七节）。合成模拟里，四种快照库（包括用真实生成分布的理想快照）的吞吐相差在 ±1% 以内。

**停止边界审计（第一版就记录）：** 每个停止决策都能拿到三个量，不需要额外的 Target 验证：
- 预测的 μ̂_i(m+1) 和决策余量；
- 补算前向给出的真实下一层，在当时冻结的校准下的增量 dG（检验快照）；
- 实际接受增量 dA：被接受路径没到叶子时为 0，到了叶子时用 bonus token（叶子处的 y*）判断（检验校准）。

合成结果（[progress/results.md](progress/results.md) 7.7 节 E）：快照部分 dG/μ̂ = 1.01–1.06；校准部分在 b≤2 时 dA/dG = 1.23–1.40，边界附近 30–44% 的决策会翻转，但后悔在 token 数的 1.5% 以内，给规划器真实参数也只多 0.24%。所以判断要不要加第七节的模块时，看后悔或吞吐影响，不只看偏差比例。

### 6. 成本

```text
Draft 层：c_Draft(𝒜′) = 在线学习的表[路径, bucket(|𝒜′|), W, w]，按实测层时间做 EMA；
          规划时乘成本裕量 f_D（b=1 时 1.0，b≥2 时 1.15，阶段 3 标定）。f_D 是有意的策略偏置：
          DP 精确优化的是加了裕量的代理目标；Θ* 的记账和开关的比较用不加裕量的实测值
等待时间：T_wait(b, K) = 在线学习的表，按实测的"回包到收到下一条 STEP"做 EMA（包含 RTT）
          两张表的每格都记样本数和最后更新的轮号；执行路径（图或 eager）或 W 变化时，相关格子降权
          上下文变化时（RTT、前缀长度），不同 K 的格子在不同时间更新，RTT 的变化会被算成 K 的成本差。
          合成（results.md 7.7 节 A）：RTT 变化时 37–41% 的轮次选错 K，但吞吐只比已知成本低 0.44%（最差 0.84%），
          因为最优 K 附近目标很平。第一版保留 EMA 表。"锚定的水平 + 差值"（锚 K 的样本只更新水平，其余 K 的样本
          只更新它和水平的差）把差距缩到 0.14%，作为阶段 3 的备选；不加锚的"水平 + 效应"不可识别，不采用
          强制 K 探测：3% 的轮次在验证时整轮换一个 K 档（除基线外的各个 K 等概率），
          记录分配概率；没有它，没被选中过的 K 的估计会停在先验上
规划器：C_plan,m+1(𝒜′) = 下一层的规划时间（编译实现实测，按 (b, W) 查表）；当前层已花的是沉没成本
ΔT_K 进入 DP 的形式（阶段 4 决定）：
  A 公共成本：给定 K，各种树形下 T_round 的差异在 ±max(1%·T_round, 0.1 ms) 以内（等价性检验）
  B 按请求可加：Σ_i f(K, n_real,i)，n_real,i = min(K, |T_i|)，折进各请求的终止项
  C 都不成立：只依赖整批真实节点总数时，DP 状态扩成 (m, 𝒜, n_total)；超预算时先用可加近似求出前几个方案，再重新排序
T_round 的分解：Target 端日志记录收到回包、开始验证、结束验证、发出 STEP 的时间戳，离线分解，不改协议；
  中间插了预填充的轮次单独标记
后台维护（GLMM 重新拟合、日志写出）：在单独的进程里跑，不进 DP；Θ_生产 按墙钟实测，自然包含它的干扰
```

## 四、理论结果

| 结果 | 表述 |
|---|---|
| 引理 0 | 在适用范围内 Â 的闭式成立；终止节点在本轮的边际价值为 0。前提：greedy 验证；只有一条路径被接受；终止事件互斥；计数口径和 completion_tokens 一致（`finished_len = matched_pos + 1`） |
| 引理 1 | π̄ 父 ≥ 子，兄弟之和 ≤ 父（对每组抽样按构造成立，取平均后保持） |
| 引理 2 | 概率权重固定时，best-first（平分时祖先优先）给出最优验证集合 |
| 引理 3 | 固定 K 时，ΔG(d+1) ≤ U(d+1) ≤ ΔG(d) |
| 定理 1 | 给定一组预先固定、只依赖 (i, m) 的增量预测和只依赖 (m, 𝒜′, x) 的成本，子集 DP 精确求解对应的有限层嵌套问题。前提：成本包含下一层的规划时间；D^build、D^reward 每轮开始时定好；K 固定，ΔT_K 是公共成本或按请求可加；吸收状态已反映在 μ̂ 里。在线滚动规划不代表真实随机过程的全局最优。精确是对加了成本裕量 f_D 的代理目标而言 |
| 命题 1 | 在静态确定性规划模型中，Locked-K 和 MPC-Free（比较总值）都达到 (K, 活跃集合) 的联合最优，MPC-Free 不切换 K。额外前提：KV 分配和 K 无关；关掉探索；所有 K 面对相同的执行约束；每个 K 的目标包含它全部的未来成本。只适用于当轮对所有 K 重新求解的版本；沿用 K_g 的轮次只有定理 1（给定 K_g 的最优），验证时重选 K_v 只改善终止阶段，补不回没建出来的节点 |
| 命题 2 | 线性损失下，按后验均值的符号行动，期望损失最小，且与何时停止采样无关；单个决策的期望损失 ≤ 0.4σ（高斯后验）或 0.5σ（一般后验） |
| 命题 3 | 对同一棵树 T，R^{K_g}(T) ≤ max_K R^K(T)。所以在模型内，规划值是重选 K 之后终止价值的下界；验证时重选 K 对终止阶段是精确的。它不说明预测是实际收益的下界，也不保证 K_v = K_g |
| 命题 4 | 如果"哪些父节点被观测到"只取决于同一请求里已观测的结果和协变量，以及按已观测数据做的策略决定，那么 M1 的 GLMM 边际似然就是正确的似然。只覆盖静态 δ_i；按位置衰减的 δ 是工程近似（三.2） |
| 定理 2 | 只在"上下文由外部决定、动作不影响以后的状态"时，逐轮最大化 A − Θ*·T 才是长期最优；真实系统里只是滚动近似。合成模拟：比知道全部未来的最优慢 1.2–1.5%，其中由忽略状态动态造成的只有约 0.2 个百分点 |

**引理 2 的证明：** 任何祖先闭合的 K 元集合，价值都不超过"不加约束时前 K 个节点的价值之和"。前 K 个节点组成的集合本身就是祖先闭合的：若 u 在集合内，它的父节点 p 满足 π_p ≥ π_u；π_p > π_u 时 p 必然在集合内，π_p = π_u 时"平分时祖先优先"保证 p 排在 u 前面。所以前 K 个集合可行，并且达到了上界。□

**引理 3 的证明：** 记 S_d 为前 d 层里价值最高的 K 个节点，m_d 是其中的最小值；不满 K 个时用价值为 0 的虚节点补足，m_d = 0。所有 π 用本轮冻结的那一版参数计算。

```text
(a) 加入第 d+1 层后，新进入前 K 的节点 N 挤掉同样多个 S_d 里的节点，被挤掉的节点价值都 ≥ m_d，
    所以 ΔG(d+1) ≤ Σ_{u∈N, π_u > m_d} (π_u − m_d)。
    每个这样的 u，父节点 p ∈ L_d 满足 π_p ≥ π_u > m_d，所以 p ∈ S_d；
    由兄弟约束，同一个 p 下这些孩子满足 Σ(π_u − m_d) ≤ π_p − m_d。
    合起来 ΔG(d+1) ≤ Σ_{p∈L_d∩S_d} (π_p − m_d) = U(d+1)。
(b) 设 n = |L_d ∩ S_d|。不在 S_d 里的节点价值都 ≤ m_d，所以 G(d−1) ≤ Σ_{S_d∖L_d} π + n·m_d，
    即 ΔG(d) ≥ U(d+1)。□
用到的条件：父 ≥ 子、兄弟之和 ≤ 父、孩子来自上一层、m_d ≥ 0、K 固定。全局 top-W 和排除终止候选只删节点，结论对子集仍然成立。
```

**命题 1 的证明：**

```text
可行集  Σ = { (𝒜_1, 𝒜_2, …) : 𝒜_{m+1} ⊆ 𝒜_m, 𝒜_m ⊆ ℰ_m }；K 只出现在目标里，不出现在约束里
问题    max_{K∈𝒦, σ∈Σ} J(K, σ)，J(K, σ) = Σ_i G_i^K(d_i(σ)) − Θ*·[C_Draft(σ) + C_plan(σ) + ΔT_K]
        "各层用不同 K 相加"不是这个系统能实现的目标：验证只给一棵树打一次分
MPC-Free 第 m 层比较的量：Ĵ_K(m) = Σ_i G_i^K(已建的树) − Θ*·ΔT_K + V^K_{m+1}(当前状态)；平局时保留当前 K
        Ĵ_K(m) 不含前 m−1 层已经支付的 Draft 和规划成本 C_paid(m)；C_paid(m) 由前缀 p 决定，和 K 无关

设 (K°, σ°) 是联合最优。第 1 层 max_K Ĵ_K(1) = J(K°, σ°)（C_paid(1) = 0），选出的 K₁ 和计划 σ₁ 也是联合最优。
模型是确定的，第 m 层的状态就是 σ₁ 的一个前缀 p。由最优性原理 Ĵ_{K₁}(m) + C_paid(m) = J(K₁, σ₁)；
对任意 K′：Ĵ_{K′}(m) + C_paid(m) = max_{σ 以 p 开头} J(K′, σ) ≤ max_σ J(K′, σ) ≤ J(K°, σ°) = Ĵ_{K₁}(m) + C_paid(m)。
所以 Ĵ_{K′}(m) ≤ Ĵ_{K₁}(m)；相等（存在多个联合最优）时按平局规则保留 K₁。K₁ 不会被替换，
树建完后 K₁ ∈ argmax_K J(K, σ₁)。Locked-K 在第 1 层就选出 K₁，同样达到联合最优。□
```

**命题 2 中常数的证明：** 设后验均值 m ≥ 0（m < 0 对称），选"继续"。损失 E[V⁻] ≤ E[(V − m)⁻] = E|V − m| / 2 ≤ σ / 2；后验为高斯时，最坏情况 m = 0，损失为 σ/√(2π) ≈ 0.4σ。□

**命题 4 的证明：** 一个请求的完整数据概率，可以按观测顺序拆成两类因子的乘积。一类是"下一个被观测到的是哪个节点"的条件概率：给定已观测的数据，它只取决于 Draft 生成的树和策略，不含 (θ, δ)，可以约掉。另一类是每个标签的条件概率 p(H_v | x_v, δ, θ)。所以似然正比于 ∫ ∏_v p(H_v | x_v, δ, θ) φ(δ) dδ。如果标签按结果丢失，选择因子就会依赖 (θ, δ)，结论不再成立。□

## 五、求解流程（第一版核心）

### 0. 冷启动

1. **捕获图：** Target 捕获 𝒦 的各档；Draft 捕获各 W 档乘以 bs ∈ {1, 2, 4, 8}。
2. **冷启动期：** 按当前 OPT 运行（τ 固定，K 取最接近 N+1 的档位），同时收集标签、快照和成本表。
3. 关键格样本足够、Θ* 稳定之后，切到 ClearTree。
4. **启动检查：** 开了 RPD 拒绝启用；拿不到 stop id 又没有部署声明时拒绝启用。

### 1. 每一轮

```text
Target：发 STEP ─────────────────────────────────────────────► 收到草稿 → 验证 → 提交 → 发下一条 STEP
Draft ：  收到 STEP → ① 在线更新 → ② 快环 → ③ 选 K_v 和验证集 → 回包 → 补算最后一层，存下概率（不继续长树）
```

### 2. ① 在线更新

- **范围检查：** batch 里有非 greedy 或受约束解码的请求时，这一批走 OPT 规则。
- **标签：** 收集被接受父节点的 y*、H 和特征，检查每轮链条末端的标签齐全；更新活跃请求的 δ；更新 β。每 M 轮把参数快照交给后台进程重新拟合，结果在下一轮的 ① 换入，一轮之内版本不变（版本号记进 `d_plan`）。
- **快照库：** 写入上一轮各层的快照。
- **Θ*：** EMA(A^real) / EMA(T^real)；不截尾，只剔除测量异常并计数。
- **成本：** 用上一轮的实测层时间和等待时间更新两张表；强制 K 轮的等待时间按分配概率记账。
- **请求状态：** 按注水规则记账预留 KV，算 D^build 和 D^reward（r_i 用 PREFILL 里 `max_new_tokens` 的原值）；已取消的请求清掉它的树和快照。

### 3. ② 快环

```text
第 1 层（选 K_g）：
  每 10 轮重新评估一次：对每个 K ∈ 𝒦，用 μ̂ 做同步嵌套 DP，
    Ĵ_K = Σ_i G_i^K(第 1 层) − Θ*·T_wait(b, K) + V_2^K，K_g = argmax；其余轮沿用上一次的 K_g，只解一次 DP
  沿用 K_g 是降开销的近似，命题 1 只对重新评估的那一轮成立。合成（results.md 7.7 节 B）：b 变化或水平跳变时
  立即重选、每轮都重选，和每 10 轮的差别都在 ±0.7% 内，所以第一版不加触发条件，只放进消融

每一层 m（已经建到第 m−1 层，当前活跃集合为 𝒜）：
  在 K_g 下，对 i ∈ 𝒜 ∩ ℰ_m 算出 μ̂_i(m)，更远的层按比例外推
  嵌套子集 DP（位掩码，每层 O(b·2^b)）：
    x_m(𝒜′) = Σ_{i∈𝒜′} μ̂_i(m)
              − Θ*·[ f_D·c_Draft(𝒜′) + 1[𝒜′ ∩ ℰ_{m+1} ≠ ∅]·C_plan,m+1(𝒜′) ]
              + V_{m+1}(𝒜′ ∩ ℰ_{m+1})
    V_m(𝒜) = max(0, max_{∅ ≠ 𝒜′ ⊆ 𝒜 ∩ ℰ_m} x_m(𝒜′))
  第一步集合的值 > 0 时，对这个集合做一次层前向；否则停止；相等时停止
规划预算：每次决策 P99 ≤ 0.1 ms；超出时先把 N_param 降到 1（合成里按路径对 δ 积分没有可测收益，results.md 7.7 节 E），
  再减少快照次数，最后把规划和层前向重叠（晚一层决策，见第七节）
```

### 4. ③ 选 K_v 和验证集

```text
best-first（平分时祖先优先；终止节点价值为 0，排在最后）
K_v = argmax_K [ Σ_i Â_i^K(实际的树) − Θ*·T_wait(b, K) ]
强制 K 探测：3% 的轮次换成另一个 K 档（等概率），记录 K_baseline、K_assigned、分配概率；收益损失计入 Θ_探索
补齐：每个请求发 K_v 个节点，不够的用占位补齐，父指针为 −1，不进接受链
验证集合一律按实际发出的 K（包括强制 K，变大或变小）用 best-first 重选，不能只改消息里的 K
某个请求没有节点（r_i = 1，或没有树 KV）：全占位，根那一行产出 1 个 token
全批都没有有效节点：走 Target decode（和开关同一条跳过路径），不进 T_wait 表；
  跳过路径修好之前，用最小 K 档的全占位验证，单独记一格
```

### 5. 投机开关（自适应）

- 每个上下文（b 档）各自记一份状态，开始时沿用静态规则的判断。
- **计时口径：** 两种模式都在 Target 调度循环上，用同一个口径计算吞吐：completion_tokens 的增量 / 有请求在跑的迭代的墙钟总和（从一次迭代开始到下一次开始）。decode 步时只当第一个 Target-only 窗口之前的先验。合成（results.md 7.7 节 D）：Target 每次迭代有 2 ms 的非 kernel 开销时，若用 kernel 时间算 Target-only 的吞吐，投机只领先 20% 左右的场景会误退出，最多损失 5.5%。
- **退出：** 用不重叠的 20 轮块检验。一块的吞吐比 Target-only 低 15% 以上，立即切到 Target-only，走 decode 图；低 3–15% 要连续两块。
- **为什么不用滑动窗口：** 每轮都检验的滑动窗口，在投机只快 5–13% 时，几百次检验里总会误判一次。探测占比有上限后，每次误退出要等 5–6 秒才回来；合成模拟里，长前缀 b=3 因此掉了 4.4%。
- **探测：** 处于 Target-only 时，只要本上下文的累计探测时间 ≤ 5% ×（Target-only 时间 + 探测时间），就探测 8 轮；探测吞吐 > (1 + 余量) × Target-only 时切回。
- **不做指数退避：** 合成模拟里，RTT 慢慢变化时退避会多亏 1.3–2.5%。
- **合成结果：** 旧参数（每 3 秒探测 15 轮）在投机一直亏的场景约 20% 的时间在探测，比直接走 Target-only 低 5–7%。新参数在长时间运行时只低约 2%，这是保留探测的代价。
- 这取代 D2 的"b≥7 走 Target-only"静态规则。实现之前，部署仍按 D2。

### 6. 宽度 W

- 前置测量里按上下文（b 档 × 前缀长度档）选定 W，写成配置。
- 在线只做长窗口的漂移检测：窗口按分钟计，而且要够长，使吞吐的标准误小于各档 W 之间的差距。发现漂移就提示重新测量，不自动切换。

### 7. 护栏

| 护栏 | 动作 |
|---|---|
| 数值一致性：按 Target top-1/top-2 差距分档的翻转率，对比 Target-only 跨形状基线。这是诊断，不是输出等价的证明：精确算术下 greedy 验证的输出和 Target greedy 相同，有限精度下的一致性由实验报告 | ≥ 3 nat 档显著偏高时报警，退回冷启动配置 |

| 模块 | 设计要点 | 什么时候加 |
|---|---|---|
| 统计决策层 | 去偏 Ṽ = V_P − b̂：b_DP(K) 为固定 K 时 DP 的选择偏差，b_Kg 为跨 K 选择扣掉 b_DP 后的残差，b_Kv 只做诊断。不确定性分两部分：可约 σ_red² = SE_MC² + SE_b̂²，不可约 σ_irr² 由端到端联合 bootstrap 估计。C_dec：\|Ṽ\| ≤ κ·σ_red 时，每次加 4 个独立样本、最多 32 个，按总方差算"再取 4 个"的期望损失下降，低于成本就停；动作取后验均值的符号；σ_irr > τ_irr 时回退到 OPT 的动作。监控池分成 C_cal（估计）和 C_audit（检验），交替分配 | E3 显示：只看点估计时，误判造成的损失 > 1%，或者 Monte Carlo 噪声明显影响决策 |
| 快照库的选择偏差处理 | 纳入概率用单步 P(纳入 \| 第 m 层状态)；主估计器用回归调整 m̂(φ) = kNN_自然(φ) + Σ_c P̂(c \| φ)·δ̂_c；随机扩展探测（带内 p_band，带外保底 p_floor，带用 DP 表里的插入损失定义）；IPW 只做诊断 | E1 显示：自然快照对"本来会停止"的状态，下一层预测偏差 > 5%。一层的数据来自补算前向（三.5），两层以上用强制多扩展一层的审计 |
| 用未接受父节点训练（M2–M4） | M2 全部验证过的父节点；M3 加 off-path 指示 o_v；M4 第二段也加 o_v。判据：off-path 效应的整个置信区间在 ±0.1 logit 内，第二段 top-1 份额变化在 ±1 个百分点内 | E2 |
| 验证集探索 | 只在 K 个名额内替换价值最低的叶节点，替换后仍祖先闭合，记录节点级的纳入概率 | E2 选了 M1，并且低排名分支的校准样本不够 |
| 在线 W 慢环 | 用模型预测各档 W 的吞吐作先验，实测核对，切换后实测变差就切回 | 前置测量显示最优 W 随时间漂移，而且可以用足够长的窗口分辨 |
| 晚一层决策 | 规划和层前向重叠：下一步的决策在当前前向运行时算好 | C++ 规划器仍超预算时 |
| MPC-Free | 每层对所有 K 规划，比较总值 | 只作对照 |

## 十二、论文取舍和已知风险

| 内容 | 处理 |
|---|---|
| 联合路径接受概率（GLMM、联合积分、命题 4） | 核心贡献 1 |
| 同步嵌套树优化（引理 0–3、定理 1、命题 1、3） | 核心贡献 2 |
| 吞吐定价的在线控制（全局价格、在线成本、自适应开关） | 系统贡献 3 |
| 第七节的模块 | 第一版不做；真实数据证明需要时再写进方法 |
| **用 T0 实测重新标定（第 7 轮，推翻上面几行的收益数字）** | 上面几行的 OPT 基线用的停止规则和真实 OPT 不同，静态基线偏弱约 4%。换成真实规则以后，原来的世界里 ClearTree 核心只比最好的静态配置高约 0.6%。用实测重新拟合成本：验证 token 约 0.026 ms 一个，几乎免费；每个请求每轮约 2.5 ms，和 K 无关；Draft 各层占一轮的一半以上；拟合误差均值 1.6%，最大 5.1%。在这个世界里，ClearTree 核心比最好的耦合静态 OPT 高约 10%，但约 90% 来自"层宽和验证数解耦"这个静态改动：W=4、K=16、τ=0.4 一套全局配置就够，ClearTree 核心在它之上平均只多 0.8%。详见 [progress/results.md](progress/results.md) 7.8 节 |
| **不同负载和简单规则（第 8、9 轮）** | 静态参数不能跨数据集通用：b≥4 时最优 τ、K 随接受率变化很大，用错极端负载的参数损失 20% 以上。ClearTree 在高接受率下少长层，主因是 logistic 校准在接受率接近 1 时饱和、被低估。一条不调参的"按 batch 算账"规则（收益之和对比 Θ* × 层成本，请求退出按图档，按请求在线校准，W 按 b 选）平均只比各数据集调好的静态配置低约 0.2%，混合负载下比单一静态配置高 3–7.5%，和 ClearTree 只差 0–2 个百分点。第 10 轮在种子 8–10 上样本外复核，加上只在 b>1 启用的开关后结论不变（纯负载平均 +0.8%，最差 −3.0%）；D42 开关在 b=1 会误退出。详见 [progress/results.md](progress/results.md) 7.9–7.11 节 |
| 等待期间预起草、定长 frontier 替换、连续宽度爬山、MPC-Free 作为主方案 | 不采用 |

**已知风险：**
- 在 3–5 ms 的 RTT 下，调好的静态规则离最优只差 0–13%；收益主要在 b≥4、网络变化和混合负载下，b=1 基本没有收益，要如实写。
- 合成模拟的收益（b≥4 时 5–10%）高于实测噪声带（1.6%–2.9%），但接受模型、快照分布和成本都按方案自己的假设生成，真实收益可能更低。
- 第 7 轮按实测重新标定后（progress/results.md 7.8 节），ClearTree 核心相对"解耦的静态 OPT 加自适应开关"平均只多约 1%，而且只在 b≥4 时出现。如果实测确认"验证 token 几乎免费"，论文和实现的主线应该先是"层宽和验证数解耦 + 自适应开关"，逐轮规划只能作为增量。
- 删掉预起草以后，网络这一维的增量只剩"把延迟单调的结论推广到树和 batch"，加上自适应开关。
- 在混合负载加 RTT 变化的场景下，如果相对"最好的静态配置 + 自适应开关"的收益 < 3%，论文主线改为系统实现、Draft KV 窗口、成本模型和自适应开关。
- 4096 前缀时 Target 验证还在走 eager，长前缀的打平点（实测 b≥3 时 Target-only 更快）要修完再看。合成模拟里小树（N=4）在 b=3–4 仍比 Target-only 快 2–12%，V2 加了这一格。
- 论文要分开陈述两件事：greedy 验证在精确算术下的算法语义（输出和 Target greedy 相同），以及有限精度下的数值一致性实验。翻转率报警只是诊断。
- 发表还需要第二组模型和标准数据集。
