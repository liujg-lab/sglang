# ClearTree 理论检验脚本

这些脚本是 ClearTree 设计文档（`python/sglang/srt/speculative/clear_tree/README.md`）里引理、命题和设计选择的数值检验，作为论文附录的可复现材料。全部是纯 Python 标准库，不依赖 SGLang、GPU 或模型权重。

**注意：** 都是合成实验，只说明机制和量级。生成器、噪声模型和参数都是人为设定的，结论能否在真实系统上成立，要看 `progress/plan.md` 里的 E1–E3。

## 运行

在本目录下直接运行，例如：

```bash
cd test_sglang_liujg/clear_tree/theory
python3 check_lemmas.py
```

每个脚本都固定了随机种子。下表的数字是 2026-11-09 用 Python 3.14 跑出来的；换 Python 版本，随机数序列可能有细微差别，数字会略有不同，但结论不应改变。模块之间可以互相导入，导入时不会运行完整实验。

## 脚本和对应的结论

| 脚本 | 检验什么 | 记录的结果 | 大致耗时 |
|---|---|---|---|
| `check_lemmas.py` | 引理 3（固定 K 时 G 的逐层增量不增）在随机树上是否成立，以及去掉兄弟约束后是否失效；引理 2（best-first 和暴力枚举是否一致） | 有兄弟约束：0 / 89,903 次违反；去掉兄弟约束：6,076 / 89,903 次（6.8%），最大违反 3.02；best-first 和暴力枚举 0 次不一致 | 1–2 分钟 |
| `oracles.py` | O1：单层活跃集合的选法；O2：嵌套约束（同步深度）的代价；O3：K 和活跃集合的联合规划 | O1：只按 μ 排序选错 8,038 / 20,000（最大损失 2.93），按 μ−c 排序遍历所有 n 为 0；成本不可加时排序法选错 1,239 / 20,000。O2（3000 次）：固定成本与活跃数无关时贪心 0 次失误、嵌套 = 自由排列；次可加档位成本时贪心 1 次失误，自由排列更好 97 次；超可加时 63 次和 1,435 次。O3：预测准确时原领先档法出错 2.7%、固定 K=4 出错 37.1%、MPC 0%；噪声 σ=0.3 时三者平均损失 0.0079 / 0.0347 / 0.0066，最大 0.447 / 0.469 / 0.193 | 10–20 分钟 |
| `oracles_extra.py` | 允许重新加入相对嵌套能多出多少；每轮开始时为所有 K 规划再锁定（A′）的效果 | 自由排列优于嵌套 51 / 1500 次，这些情形的相对差距中位数 1.97%、最大 18.0%，全部情形平均 0.115%；A′ 在预测准确时 0 损失，噪声 σ=0.3 时出错 27.7%、平均损失 0.0106 | 约 10 分钟 |
| `topw_bias.py` | μ̂ 的模拟是否必须做全局 top-W 截断 | 不做截断（只给前 K 个里的父节点生成孩子）偏高：W=2 +9.8%，W=4 +14.5%，W=8 +6.4%，W=16 −0.8%；做截断后偏差在 ±1.2% 以内，MAE 降一半以上 | 数分钟 |
| `block_bootstrap.py` | 层内存在共同因子时，逐节点抽样和整层抽样的偏差 | ρ=0：两者都可以忽略；ρ=0.5 / 1.0 / 2.0：逐节点 +24.1% / +38.2% / +38.3%，整层 +6.2% / +4.6% / +3.4% | 10–20 分钟 |
| `delta_joint.py` | 共享的请求随机效应 δ：逐边预测再连乘、MAP 代入，相对按路径联合积分的偏差 | 后验标准差 0.5、η=1：深度 4 时逐边 −9.5%、MAP −4.2%；深度 8 时 −33.1% 和 −25.1%。标准差 1.0、深度 8：逐边最多 −65.7% | 1 分钟以内 |
| `selection_abc.py` | 选择偏差：只用 A 池；A 选候选、B 重新规划再选；再用 C 估值固定方案 | 估值偏差（σ=0.05 / 0.15）：A +0.037 / +0.272，A/B +0.039 / +0.281，A/B/C −0.003 / −0.001；A/B 的选择损失比 A 更大 | 10–20 分钟 |
| `selection_abc2.py` | 加上继续/停止判断后的实际价值：A、A/B、A/B/C、合并池选择（P）加 C 估值、P 加容差、只用 P | 平均损失（σ=0.15）：A 0.119，A/B 0.126，A/B/C 0.132，P/C 0.073，P/C 加容差 0.0685，只用 P 0.0684 | 10–20 分钟 |
| `boundary_rule.py` | 继续/停止规则：只看 P、总是用 C、只在边界附近用 C（分区） | σ=0.15：误判继续 1.8% / 0.8% / 1.2%，误判停止 0.2% / 3.0% / 0.9%，损失 0.0694 / 0.0732 / 0.0693，分区规则只在 6% 的轮次用 C；σ=0.3：误判继续 5.8% → 4.0%（分区），C 用 10% | 数分钟 |
| `cross_round.py` | 跨轮状态：逐轮最大化 A − Θ·T，相对考虑跨轮状态的最优策略（事先知道后续全部难易）损失多少 | 平均 1.48% / 1.46% / 1.19%（前缀成本 κ = 0 / 0.002 / 0.02），最大 2.89% | 数分钟 |
| `cross_round_rollout.py` | 把上一行的差距拆成"忽略状态动态"和"不知道未来"：rollout 基线只知道当前窗口内的难度、对以后按平均值估计，但考虑前缀增长和请求结束 | 相对 Oracle：逐轮规则 1.48% / 1.46% / 1.19%，rollout 1.28% / 1.23% / 0.97%（κ 同上）。忽略状态动态只占约 0.2 个百分点 | 数分钟 |
| `mpc_free_check.py` | 命题 1：确定性模型里，Locked-K、MPC-Free（比较总值）、MPC-Free（只比较后续增量）是否达到 (K, 活跃集合) 的联合最优；审查给的"各层用不同 K 相加"的目标是否可实现 | 1500 个实例：Locked-K 和 MPC-Free（总值）都 0 次劣于最优，MPC-Free 0 次切换 K；只比较后续增量 241 次更差（749 次切换 K）；混合 K 的目标在 1213 次里超过联合最优，说明它不对应任何执行 | 约 10 秒 |
| `mpc_noise.py` | 预测带逐层独立噪声时，Locked-K、Locked-K 加验证时重选 K、MPC-Free 的损失 | 平均损失（σ=0.15 / 0.3）：0.0072 / 0.0213；0.0042 / 0.0105；0.0023 / 0.0061。每轮解的 K 计划数 4.1 对 6.2 | 1–2 分钟 |
| `two_stage_k.py` | 层结果随机、建完树再选 K 的两阶段问题，用 Bellman 精确求最优；比较滚动规划方案和固定建树 K | 相对精确最优（1000 个实例，5 种噪声设定）：Locked-K 0–0.17%，加重选 K 0–0.07%，MPC-Free 0–0.02%；固定 K_g=2 损失 10.8–11.8%，固定 K_g=8 损失 1.2–1.3%；请求效应完全共享时三者都等于最优。设定用环境变量 `SETTING` 选 | 每种设定数分钟 |
| `seq_c_pool.py` | 顺序 C 池的可选停止：z=2 反复检查、用历史标准差、Pocock 边界、固定 32 个样本、贝叶斯停止 | V=0 时提前停止的比例：28.2% / 16.7% / 4.9%（Pocock 2.511）。采样有成本时，贝叶斯停止的总成本最低，或比最低的只高 10% 以内 | 数分钟 |
| `bias_vs_se.py` | 选择偏差是扣除，还是放大标准误；偏差是否要按 \|V_P\|/SE 分层估计 | 边界附近的偏差只有平均值的 1/10 到 1/2；σ=0.3 时，不分层扣除使误判停止从 2.1% 升到 5.5%（损失 0.1976 → 0.2021），分层扣除 0.1985 | 数分钟 |
| `ipw_library.py` | 快照库在选择性扩展下的估计：不加权、kNN 内 IPW（不同截断上限）、回归调整（自然样本 kNN 加探测样本合并估计的偏移） | 偏差 / RMSE：不加权 +0.25 ~ +0.45 / 0.25–0.45；IPW 不截断 +0.11 ~ +0.17 / 0.25–0.32，有效样本数 10–42；回归调整 −0.04 ~ −0.07 / 0.07–0.10 | 数分钟 |
| `glmm_cluster_size.py` | 命题 4：只用被接受父节点训练时，"容易的请求样本多"会不会带偏 GLMM；按位置缺失和按结果缺失的对比 | 真值 a=0.4、σ=0.8。固定输出长度：M1 0.398 / 0.810；固定 20 轮（难的请求 27 个标签、容易的 70 个）：M1 0.390 / 0.800，按位置丢标签 0.403 / 0.800，按结果丢标签撞到网格边界，把节点当独立样本 a=0.599 | 约 1–2 分钟 |

端到端的合成模拟器（吞吐、规划器耗时、模块消融）在 [`../sim/`](../sim/README.md)。

## 和设计文档的对应

| 设计文档中的结论 | 脚本 |
|---|---|
| 引理 2（best-first 最优）、引理 3（逐层增量不增）和兄弟约束的必要性 | `check_lemmas.py` |
| 命题 4（单层子集选择）、定理 1 的闭式特例、同步嵌套约束的代价 | `oracles.py`、`oracles_extra.py` |
| 命题 1（静态确定性模型中 Locked-K 和 MPC-Free 等于联合最优；MPC-Free 必须比较总值） | `mpc_free_check.py`、`oracles.py`（O3）、`oracles_extra.py` |
| 命题 3 和主方案（固定 K 建树 + 验证时重选 K）；两阶段近似的损失 | `two_stage_k.py`、`mpc_noise.py` |
| 命题 2 的停止规则；偏差分层 | `seq_c_pool.py`、`bias_vs_se.py` |
| 命题 4（M1 的似然） | `glmm_cluster_size.py` |
| 快照库的单步纳入概率和回归调整 | `ipw_library.py` |
| μ̂ 必须模拟全局 top-W；整层快照 | `topw_bias.py`、`block_bootstrap.py` |
| 请求随机效应要按路径联合积分 | `delta_joint.py` |
| P 池选方案、分区判断（命题 2） | `selection_abc.py`、`selection_abc2.py`、`boundary_rule.py` |
| 定理 2 的适用范围（跨轮状态） | `cross_round.py`、`cross_round_rollout.py` |
